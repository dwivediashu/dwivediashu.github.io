One-time setup

This connects the login to your GitHub repository so the website can publish your edits. You only do this once (and again when the GitHub key expires).

Step 1 — Create a GitHub key (2 minutes)

  1. Open GitHub → New fine-grained token (you must be signed in to GitHub).
  2. Token name: Website editor. Expiration: choose the longest available (e.g. 1 year).
  3. Repository access: “Only select repositories” → choose dwivediashu.github.io.
  4. Permissions → Repository permissions → Contents: “Read and write”. Leave everything else as it is.
  5. Click Generate token, then copy it (it starts with github_pat_).

Step 2 — Choose your login

Use 12+ characters. A short phrase of random words is strongest.
